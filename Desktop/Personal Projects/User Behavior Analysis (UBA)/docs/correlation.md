# Security Event Correlation

## Objective

The correlation layer attempts to identify relationships between security events generated by different security controls.

## Data Sources

- UBA
- SIEM
- EDR
- IPS
- Network telemetry

## Correlation Keys

Potential correlation attributes include:

- User
- Host
- Source IP
- Destination IP
- Process
- Timestamp
- Domain
- Hash
- Alert ID

## Time-Based Correlation

Events can be correlated within a defined investigation window.

Example:

UBA Alert
  T+0

EDR Event
  T+30 sec

IPS Alert
  T+45 sec

These events may belong to the same investigation context.

## Entity Correlation

Example:

User:
`labuser`

Host:
`LAB-WIN-01`

Source IP:
`192.168.x.x`

The same entities appearing across multiple telemetry sources increase contextual relevance.
